# Astronomía de datos con Python 🔭

Pequeño proyecto personal para aprender análisis de datos
astronómicos utilizando Python y Astropy.

https://learn.astropy.org/tutorials/plot-catalog.html 

## Contenido

- Lectura de catálogos astronómicos
- Coordenadas celestes con Astropy
- Análisis de magnitudes
- Índices de color
- Visualización con Matplotlib
- Análisis de objetos jóvenes

## Tecnologías

- Python
- Astropy
- NumPy
- Matplotlib
- Jupyter

## Datos

Young-Objects Compilation


## Preparar entorno

activate venv

`.venv\Scripts\Activate.ps1`

Activate scripts execution

`Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

update pip

`python -m pip install --upgrade pip`

install Astropy and Jupyter

`python -m pip install astropy jupyter matplotlib numpy`
